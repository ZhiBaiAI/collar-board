# 环境差异（隐藏地形）

> 预发与线上、本地与 CI 的差异，对 AI 是**隐藏地形** ——
> 排查时可能遇到「明明代码对的，就是不生效」的无法解释现象。
>
> **排障第一原则：遇到不可解释的现象，先怀疑环境，再怀疑代码。**

## 排障顺序（建议）

1. 确认代码版本：跑的是不是我以为的那份代码
2. 确认配置：生效值是不是我以为的那个值
3. 确认数据源：查的是不是我以为的那个库
4. 确认灰度：当前用户/流量是否命中新逻辑
5. **以上都确认无误，才开始怀疑代码逻辑**

## 环境差异的登记要求

引入新的环境差异时（例如新增一套灰度环境）：
1. 在本文件补一行差异
2. 在 `AGENTS.md` 关键约定速查表显式声明（AI 每会话必读）
3. 影响面大的，另起 ADR 记录「为什么必须有这个差异」
